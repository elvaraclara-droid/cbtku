# Panduan Pengguna — Siswa (Peserta Ujian)

1. **Login Ujian (`/login`):**
   - Pilih tab **Login Ujian Siswa**.
   - Masukkan **Username / NIS / NISN**, **Password**, dan **Token Ujian** yang dibagikan oleh Pengawas.
2. **Check-In Ujian:**
   - Jika diminta ganti password sementara, buat password baru minimal 8 karakter (kombinasi huruf dan angka).
   - Apabila ujian tidak mengaktifkan verifikasi wajah (kondisi default), Anda langsung masuk ke layar pengerjaan tanpa akses kamera.
   - Apabila verifikasi wajah aktif, ikuti pengambilan 1 foto atau ajukan verifikasi manual Pengawas jika kamera terkendala.
3. **Mengerjakan Soal:**
   - Masuk mode layar penuh dan hindari berpindah tab/aplikasi selama ujian.
   - Jawaban otomatis tersimpan (`SAVED`). Jika internet terputus (`OFFLINE`), tetap lanjutkan mengerjakan karena jawaban tersimpan aman sementara di perangkat dan akan tersinkronisasi saat koneksi pulih.
   - Gunakan **Tandai Tinjauan** dan panel nomor soal di kanan untuk memeriksa kembali jawaban.
4. **Mengirim Ujian:**
   - Klik **Kirim Ujian**, periksa jumlah soal terjawab dan belum terjawab, lalu konfirmasi pengiriman. Tunggu konfirmasi bahwa jawaban telah tercatat di server.
